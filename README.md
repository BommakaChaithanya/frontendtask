# Frontend Task - Demo Website

This project demonstrates basic frontend concepts using HTML, CSS, and JavaScript.

## How to Run
1. Open `index.html` in your browser.
2. Click the button or submit the form to see interactivity.

## Files
- `index.html` — main webpage
- `style.css` — styling
- `script.js` — interactivity
- `README.md` — project info

## Deployment
You can deploy this project on Netlify or Vercel by uploading the folder or connecting your GitHub repository.
